# Blank company setup worksheets

These files are reusable interview and delivery templates. Keep the originals blank in the public repository. Initialize private working copies with `python3 setup_company.py` from the repository root, or copy them into an approved private workspace.

- [Company profile](company-profile.md): business, first workflows, actual tools, owners and constraints.
- [Process map](process-map.md): current steps, tools, owners, handoffs, exceptions and completion evidence.
- [Discovery notes](discovery-notes.md): dated interview checkpoints, provenance, linked corrections and next questions.
- [Setup progress](setup-progress.md): resumable decisions, evidence, blockers and next actions.
- [Connection plan](connection-plan.md): exact prerequisites and verification for each chosen connection.
- [Pilot acceptance](pilot-acceptance.md): allowed/denied journeys and evidence needed to launch.

Follow [SETUP.md](../SETUP.md) and [the phase guide](../docs/19-guided-company-setup.md). Use aliases and source references when sufficient. Never put passwords, tokens, raw transcripts, student/customer records or infrastructure state in these worksheets. Git exclusion is not a privacy guarantee; storage and the assistant used to process answers must be approved by the company.
